🚀 Welcome to My Static Website

Hosted on Amazon S3 using Terraform

About This Project

This is a simple static website hosted on Amazon S3. The infrastructure is managed using Terraform, making it reproducible and version-controlled.

Key Features

  • ✅ Hosted on Amazon S3
  • ✅ Infrastructure as Code (Terraform)
  • ✅ Public read access enabled
  • ✅ Automatic index.html serving
  • ✅ Cost-effective hosting
  • ✅ High availability and durability

Architecture Overview

Components Used:

  • AWS S3 Bucket - For storing static files
  • S3 Website Configuration - To enable static hosting
  • S3 Bucket Policy - To allow public read access
  • Terraform - Infrastructure management

Terraform Configuration

This project uses Terraform to manage:

  • S3 bucket creation and configuration
  • Website hosting settings
  • Public access permissions
  • File uploads (HTML, CSS)

Deployment Steps

1

Initialize Terraform: terraform init

2

Plan: terraform plan

3

Apply: terraform apply

4

Access: Visit the website endpoint in your browser
